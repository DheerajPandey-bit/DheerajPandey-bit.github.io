# To-Do List Web App

A simple and responsive To-Do List application built using HTML, CSS, and Vanilla JavaScript. Users can add tasks, mark them as completed, and delete them without reloading the page.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Responsive design
- Instant UI updates
- Beginner-friendly code

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript


## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension (if not already installed).
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. Start adding, completing, and deleting tasks.

## How to Use

- Type a task into the input field.
- Click **Add Task** or press **Enter**.
- Click a task to mark it as completed.
- Click the **Delete** button to remove a task.
